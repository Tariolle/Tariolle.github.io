# Florent Tariolle Portfolio

Personal research portfolio built with Astro and deployed to [tariolle.github.io](https://tariolle.github.io).

## Development

```bash
pnpm install
pnpm dev
pnpm build
```

Projects are defined in `src/data/work.ts`; the CV is loaded from `Tariolle/curriculum-vitae`. Pushes to `main` deploy through GitHub Actions.
